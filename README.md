# 键盘触控 Demo

这是一个用于验证“蓝牙键盘快捷键模拟触屏”的 Android Demo。

## 快捷键

组合快捷键：

- `Ctrl + Backspace`：执行系统返回
- `Ctrl + Alt + ↑ / ↓`：执行短距离上下滑动

启用服务后会显示一个灰白色半透明虚拟指针：

- 小键盘 `8` / `5` / `4` / `6`：移动指针（上/下/左/右）
- 按住小键盘方向键：逐级加速
- 小键盘 `0` / 小键盘 Enter：点击指针当前位置
- 小键盘 `-`：执行系统返回
- 按下点按键即开始触摸，移动实时生效，松开结束触摸
- 点击、长按、滑动由 Android 根据完整触摸轨迹判断
- 移动轨迹按连续手势分段提交，保持手指状态
- 按住并移动：松开后执行从起点到终点的滑动

坐标使用屏幕百分比，方便在不同分辨率的手机上测试。

## 安装测试

1. 在 GitHub 新建仓库并把本目录推送上去。
2. 打开仓库的 **Actions**，运行 **Build APK**。
3. 下载 `keyboard-touch-demo-debug` artifact 中的 `app-debug.apk`，安装到手机。
4. 打开应用，点击“打开无障碍设置”，启用“键盘触控 Demo”。
5. 连接蓝牙键盘，在任意应用中测试快捷键。

Android 的安全模型要求用户主动启用无障碍服务；应用本身不能静默获得全局触屏注入能力。

## 覆盖安装

Demo 使用固定的测试签名，并根据 GitHub Actions 运行次数自动递增 `versionCode`，后续构建出的 APK 可以直接覆盖安装。

如果手机上安装的是此前版本的临时 debug 签名 APK，第一次切换到固定签名版需要先卸载旧版；安装固定签名版后，后续版本即可直接覆盖安装。

## 本地构建

需要 JDK 17、Android SDK 35 和 Gradle 8.10.2：

```bash
gradle assembleDebug
```
# 本地 TODO 网页工具（离线 / 可缓存 / 表格 + Memo）

这是一个纯静态网页工具（不需要后端、不需要联网），用于把 TODO 以**表格**形式管理，并且：

- **缓存 TODO 状态**：勾选/取消勾选会自动保存到浏览器 `localStorage`
- **修改标题**：标题输入框修改后会自动保存
- **可编辑列**：每个单元格可直接编辑（Enter 结束编辑），会自动保存
- **Memo 备忘列**：最右侧 `Memo` 专门用于保存备忘信息
- **重置选项**：支持“重置勾选 / 重置标题 / 清空当前缓存 / 清空全部缓存”

## 使用方式

1. 用浏览器打开 `index.html`（双击即可）。
2. 导入 TODO：
   - 点击 **导入 .md** 选择本地文件
   - 或点击 **粘贴内容**，粘贴 Markdown 表格 / TSV / CSV / Markdown 勾选项
3. 勾选、编辑标题、编辑单元格都会自动保存到本地缓存。

## 多清单（多个标题对应多个 TODO 表）

- 顶部新增 **“清单”下拉框**：可以选择已存在的清单进行切换
- 点击 **“新建”**：创建一个新的空清单（有独立缓存）
- 修改标题会自动更新下拉框中的名称

## 支持的导入格式

### 方式 1：Markdown 表格（推荐）

列名建议为：`Item, Owner, ETA, Details, Progress, Output, Memo`

`Item` 列支持前缀：

- `[ ] Requirement KickOff`
- `[x] Requirement KickOff`

### 方式 2：TSV / CSV（从 Excel 复制也常是 TSV）

第一行是表头，包含 `Item` 与 `Owner` 即可识别，其它列可选：`ETA/Details/Progress/Output/Memo`。

### 方式 3：Markdown 勾选项

- `- [ ] 任务`
- `- [x] 已完成`
- `* [ ] 任务`

导入后会映射到表格的 `Item` 列，其它列为空。

## 导出

点击 **导出 .md** 会导出为 **Markdown 表格**（包含 `Memo` 列）。

## 缓存说明

- 缓存使用 `localStorage`，数据只在本机浏览器里。
- “清空当前清单缓存”会删除当前清单对应的缓存键；你仍可继续操作，后续会重新保存。
- “清空全部缓存（本工具）”会清掉本工具保存的所有清单状态、标题与 Memo。
